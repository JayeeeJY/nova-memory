# Nova Memory のローカルプレビューを使う

[English](GETTING_STARTED.en.md) · [简体中文](GETTING_STARTED.md) · [繁體中文](GETTING_STARTED.zh-Hant.md) · 日本語

[製品紹介](../README.ja.md)

GitHub で公開しているのは **v0.1.0** のローカルソースプレビューです。Apple Silicon Mac で自分でビルドしてください。開発者署名、公証、別のマシンでのインストーラ確認は、まだ準備中です。バージョン番号、更新履歴、GitHub Release は、このソースプレビューの名前です。署名済みインストーラがあることでも、実クライアントや実機の受け入れが終わったことでもありません。いまのデスクトップの操作名は中国語です。以下は従うための手順であり、Mac で実行し終えた記録ではありません。

## ビルドして開く

macOS 14 以降、macOS SDK 付きの Xcode、Rust 1.97.1、Python 3.11 以降を用意します。

```sh
git clone https://github.com/JayeeeJY/nova-memory.git
cd nova-memory
cargo fetch --locked
./script/build_and_run.sh
```

入口は、新しい `.artifacts/` ディレクトリにランタイムとデスクトップアプリをビルドし、その候補を開きます。依存の版は `Cargo.lock` で固定されています。ビルドされたアプリは、ローカルのランタイムを同梱します。

別のテスト用ライブラリを使うときは、新しい絶対パスと空いているポートを指定します。

```sh
./script/build_and_run.sh \
  --profile-dir "/absolute/path/to/new-nova-profile" \
  --port 3060
```

ビルドは依存をダウンロードし、Xcode のコマンドラインツールを使います。コンパイラが見つからないときは、Xcode の設定でコマンドラインツールが入り、選択されていることを確認します。

## 最初の保存

1. アプリを開き、「开始本地使用」を選びます。
2. ワークベンチで「留住一段记忆」を選び、残したい短い資料を貼り付けて保存します。
3. 「AI 整理」で、原文、取り込み記録、処理状態を見ます。
4. モデルの準備ができたら、実行設定でモデル、サービスのアドレス、処理の仕方を選び、整理をオンにします。画面上の設定名は中国語です。

モデルが未設定でも、原文は残って待機します。モデル接続と抽出の質は別に確認します。結果はその後も修正できます。

## 別の AI で使う

ワークベンチの「连接」が、選んだプラットフォームの手順を出します。

- 継続して使うときは、対象の AI に収集または読み取りの範囲を選び、対応する MCP 設定を入れます。
- 一時的に渡すときは、「记忆库」で記録を選び、一度きりの文脈をプレビューしてから、相手のツールへコピーまたはダウンロードします。
- すでに送った文章は、受け取った側が保持します。その後の版の修正と接続の取り消しは、その後の Nova へのアクセスに働きます。

ChatGPT や Grok のようなリモートコネクタには、到達できるアドレス、認証、対応するアカウント設定が必要です。具体的な手順は、ワークベンチがそのとき示すプラットフォームの説明に従ってください。

## 原文、版、修正

「记忆库」でプロジェクトや話題を開き、出典と当てはまる条件を展開します。「AI 整理」で、どこが不正確か、どの場面にだけ当てはまるかを Nova に伝えます。修正は出典と履歴を残します。

モデルが見る資料と処理の範囲は、いまの設定によります。リモートサービスへ接続すると、関係する内容はその設定先へ送られます。ローカルの暗号化保存は、その送信を止めません。

## データとバックアップ

既定のデータディレクトリは `~/Library/Application Support/Nova Memory/local-workspace-v03` です。サービスを止めたあとも、資料と設定はこのディレクトリに残ります。アプリのウィンドウを閉じてもサービスが動き続けることがあります。止めるときはアプリの「停止」を使います。

バックアップは、ワークベンチの設定とデータの領域で扱います。暗号化バックアップの確認には、バックアップファイルと対になる Vault の鍵が必要です。デスクトップの「运行设置 → 加密备份」からファイルを選び、確認して、別のコピーを開きます。

確認用のコピーでは、収集、自動整理、AI 接続は止まったままです。再び有効にする前に、バックアップより後の削除と取り消しを確認します。

## 開発時の確認

```sh
python3 -m unittest discover -s scripts/tests -p 'test_*package.py'
python3 -m unittest discover -s scripts/tests -p 'test_desktop_local_signing.py'
```

各パッケージスクリプトの引数は `--help` で見られます。

```sh
python3 scripts/package-local.py --help
python3 scripts/package-desktop.py --help
python3 scripts/sign-desktop-local.py --help
```
